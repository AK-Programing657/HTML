Introduction to CSS

CSS stands for Cascading Style Sheets. It is a style sheet language used to describe the presentation of a document written in HTML. While HTML creates the structure, CSS handles the design, layout, and visual appeal. Without CSS, every website would be just black text on a white background.

Three Ways to Add CSS

  • Inline CSS

    You write CSS inside the style attribute of an HTML tag. Example:

    . This is not recommended for large projects.

  • Internal CSS

    You write CSS inside a style tag in the head section of your HTML file.

  • External CSS

    You create a separate file like style.css and link it with link rel="stylesheet" href="style.css">. This is the best and most professional practice because it keeps your code clean and reusable.
